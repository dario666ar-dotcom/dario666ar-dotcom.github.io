# LumenStore

Sitio web de venta de insumos de iluminacion ubicado en el centro de la ciudad de La Plata, Argentina.

## Proposito

Proyecto desarrollado como Pre-Entrega del curso de Desarrollo Web de TalentoTech.
Aplica HTML semantico, CSS externo, Flexbox, Grid, diseno responsive, Google Fonts,
Font Awesome, formulario con Formspree y mapa embebido de Google Maps.

## Estructura del proyecto

    /
    ├── index.html
    ├── style.css
    └── README.md

## Secciones

- Header y Nav: barra fija con logo y menu desordenado.
- Hero: banner con gradiente de fondo.
- Productos: 6 cards organizadas con Flexbox.
- Resenas: 4 opiniones organizadas con CSS Grid.
- Contacto: formulario (Formspree), datos y mapa del centro de La Plata (Plaza Moreno).
- Footer: tres columnas con informacion, contacto y redes sociales.

## Tecnologias

- HTML5 semantico
- CSS3 (Flexbox, Grid, Media Queries, variables CSS)
- Google Fonts (Poppins y Nunito Sans)
- Font Awesome 6
- Formspree (formulario de contacto)
- Google Maps Embed
